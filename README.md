# SmartFridge

Умная система для анализа продуктов. Дисплей на холодильник + синхронизированное приложение/сайт/бот.

## Что это

SmartFridge — система, которая сканирует продукты, ведёт инвентарь, следит за сроками, предлагает рецепты и помогает заказать недостающее.

При покупке продуктов пользователь подносит их к камере на дисплее. Система распознаёт этикетку или сам продукт, считывает название, срок годности, КБЖУ и добавляет его в цифровую базу холодильника.

## Компоненты

**Дисплей** — сенсорный экран + мини-ПК + камера. Крепится на дверцу холодильника или встраивается в неё. Основное устройство системы.

**Мобильная версия** — приложение / веб-сайт / Telegram-бот. Синхронизируется с дисплеем через интернет.

**Датчики** — температура, влажность, свет. Подключаются к дисплею для контроля условий хранения.

## Функции

- Сканирование этикетки — чтение текста с фото
- Распознавание продукта — определение продукта по фото с помощью ИИ
- Инвентарь — список всех продуктов с параметрами
- Контроль свежести — слежение за сроками и предупреждения
- Рецепты — подбор блюд из имеющихся продуктов
- Генерация рецептов — создание новых рецептов через ИИ
- ИИ-помощник — чат для вопросов и подсказок
- Голосовое управление — управление голосом, помощь с готовкой
- Мобильная синхронизация — связь с телефоном
- Заказ продуктов — список покупок и ссылки на маркеты
- Настройки — яркость, Wi-Fi, звук и т.д.
- Статистика — добавлено, испорчено, сэкономлено
- Офлайн-режим — работа без интернета
