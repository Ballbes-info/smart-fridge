# Наглядная главная

Категория продукта определяет одноцветную SVG-иконку; неизвестная категория отображается упаковкой. Поле берётся из ProductGroup.details, без догадок по названию.

Покупки можно отметить купленными с главной. Форма использует существующий POST /shopping/action, CSRF, сигнатуру версии записи и одноразовый ключ операции. После обработки сервер возвращает на главную с актуальными списками. Повторная отправка того же ключа не переключает покупку обратно. return_to допускает только фиксированное home для toggle; произвольных перенаправлений нет. Ошибки остаются в стандартных flash-сообщениях, обычные страницы покупок сохраняют своё поведение.

Питание использует карточки с существующими фото выбранных блюд, пустые слоты — компактные действия добавления. Рецепты представлены одним основным действием с графическим символом; пустая статистика компактнее. Цвета остаются приглушёнными.

Добавлен регрессионный тест формы покупки, CSRF, повторной отправки, возврата и отказа изменения чужой записи. В этой сессии среда исполнения недоступна: тест не запускался. Структура блоков Jinja и изменённые маршруты просмотрены; визуальная проверка браузером не выполнена.
