# Интерфейс для повседневных задач

Главная `/home` теперь показывает данные вместо каталога разделов:

- Наличие продуктов, сроки в ближайшие три дня и просрочку. Учитываются только личные и доступные общие места, партии с нулевым остатком исключены. Сводка не зависит от настройки отправки уведомлений.
- Личные и доступные семейные покупки, важные позиции показаны первыми. Это ожидающие покупки, а не прогноз даты похода в магазин.
- Личный план питания на сегодня при действующем премиум-доступе, дневник и заданную пользователем цель по калориям. План и съеденная еда разделены; неизвестные калории не подменяются полноценным результатом.
- График числа операций использования и списания **личных** продуктов за семь календарных дней по Москве. Значения доступны также таблицей. Это не график массы, суммы или «сэкономленных» денег.
- Переход к существующему подбору рецептов. Главная не вызывает ИИ, не запускает подбор и не расходует лимиты.

Пустые состояния объясняют следующий шаг. `/home` возвращает `Cache-Control: no-store`. Изменения данных по GET не добавлены; формы и проверки доступа сохранены.

## Навигация и оформление

На экранах до 900 px основные задачи доступны в нижней панели: Сегодня, Продукты, Покупки, Питание, Ещё. Рецепты, семья, статистика, история и помощник доступны через Ещё. Выше 900 px используется боковая панель. Питомец учитывает высоту нижней панели и не ходит по кнопкам навигации.

Раздел «Продукты» сразу открывает запасы. Места хранения, ближайшие сроки и подбор блюд доступны рядом со списком. Сохранены прежние маршруты и доступ ко всем возможностям.

Общий файл `static/css/everyday.css` дорабатывает существующую палитру, светлую и тёмную темы, карточки, поля и кнопки. Основные элементы управления увеличены для касания; поля на телефоне имеют шрифт 16 px. Настройки на узких экранах доступны через меню. Сообщения об успешном сохранении теперь видны вместе с ошибками.

## Проверка

`python -m unittest discover -s tests -v`

Семь тестов покрывают пустой аккаунт, границы сроков, чужие данные, отзыв семейного доступа, покупки, личное меню и тариф, московские границы графика, отсутствие записей при чтении, основные маршруты и запрет доступа без входа. Тесты создают отдельную временную БД.

Также проверены синтаксис изменённого JavaScript, компиляция всех Jinja-шаблонов и `git diff --check`.

Визуальная проверка в браузере в среде разработки не завершена: локальный Chromium не запускается из-за ограничения socket(), а облачный браузер не имеет доступа к локальному серверу. Перед слиянием нужно проверить ширины 320/390, 768 и 1024 px, обе темы, открытие и закрытие меню, длинные названия и формы на реальных устройствах.
