# Ограничения питания
Личные настройки: Питание → Ограничения. Хранятся в NutritionProfile.values.dietary, новая таблица не требуется. Сохранение с CSRF и проверкой revision. Диагнозы не передаются генерации ИИ.

Подбор сканирует 24 рецепта текущей страницы каталога; количество исключений относится только к этой странице. Не заявляет проверку всего каталога или медицинскую пригодность. Аллергены проверяются по именам, примечаниям и исходному тексту ингредиентов. Словарь эвристический, неполный: синонимы, скрытые компоненты и перекрёстный контакт требуют ручной проверки. Составные продукты с неуточнённым составом исключаются консервативно. Безлактозное молоко не считается безопасным при аллергии на молоко.

Выбор возраста добавляет необходимые напоминания; не подтверждает безопасность текстуры. До года подбор заблокирован. При заболеваниях используются конкретные введённые ограничения, а не автоматически назначенная диета. Целиакия включает проверку глютеновых злаков. При ограничении углеводов неизвестные данные исключают блюдо. Расчёт приблизительный; предел проверяется с фактической порцией при сохранении меню. Автоматический рацион при ограничениях отключён. Старые записи плана не переписываются, после смены настроек их нужно проверить. Общий каталог и подбор по запасам остаются общими, на карточке показывается проверка ограничений.

Источники правил и границ:
- https://www.nhs.uk/conditions/food-allergy/
- https://www.nhs.uk/baby/weaning-and-feeding/food-allergies-in-babies-and-young-children/
- https://www.nhs.uk/baby/weaning-and-feeding/foods-to-avoid-giving-babies-and-young-children/
- https://www.niddk.nih.gov/health-information/diabetes/overview/healthy-living-with-diabetes

Проверка: python -m unittest discover -s tests -p test_dietary.py
Нужны дополнительные интеграционные проверки POST /home/nutrition/restrictions (CSRF, другой owner, stale revision), сохранения плана с несколькими порциями, смены настроек, отображения на телефоне и в обеих темах.
