SmartFridge — Умная система для анализа продуктов. Она представляет собой дисплей на холодильник и синхронизированное приложение/сайт/бот для мобильного использования системы. Для дисплея можно будет добавить датчики для большего контроля.
Дисплей - сенсорный дисплей + мини-пк + камера. Прикреплен на холодильник.
Мобильная версия - приложение/веб-сайт/тгбот для удобного использования сервиса.
Датчики - датчик температуры, датчик влажности, датчик света.
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Дисплей - физическая часть проекта. Устройство, которое крепится на дверцу холодильника (или встраивается в неё). Состоит из нескольких компонентов, соединённых между собой:

Функции дисплея:
1. Сканирование этикетки - чтение текста с фото
2. Распознавание продукта - определение продукта по фото с помощью ИИ
3. Инвентарь - список всех продуктов с параметрами
4. Контроль свежести - слежение за сроками и предупреждения
5. Рецепты - подбор блюд из имеющихся продуктов
6. Генерация рецептов - создание новых рецептов через ИИ
7. ИИ-помощник - чат для вопросов и подсказок
8. Голосовое управление - управление голосом, помощь с готовкой блюд
9. Мобильная синхронизация - связь с телефоном
10. Заказ продуктов - список покупок и ссылки на маркеты
11. Настройки - яркость, Wi-Fi, звук и тд.
12. Статистика - добавлено, испорчено, сэкономлено
13. Офлайн-режим - работа без интернета
14. Добавление датчиков
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Мобильная версия — программная часть проекта. Не физическое устройство, а приложение, сайт или бот, которые работают на телефоне или компьютере пользователя. Синхронизируется с дисплеем через интернет.

Функции мобильной версии:
1. Синхронизация с дисплеем — продукты, добавленные на телефоне, появляются на дисплее, и наоборот
2. Все функции дисплея, кроме: голосовое управление, добавление датчиков
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Датчики — физическая часть проекта. Дополнительные компоненты, которые подключаются к дисплею для контроля условий хранения внутри холодильника.

Датчики:
1. Датчик температуры — измеряет температуру внутри холодильника
2. Датчик влажности — измеряет влажность внутри холодильника
3. Датчик света — определяет, открыта ли дверь

Функции датчиков:
1. Контроль температуры — если температура выше нормы, продукты портятся быстрее. Система предупреждает.
2. Контроль влажности — если влажность ниже нормы, овощи вянут. Система предупреждает.
3. Контроль двери — если дверь открыта долго, система предупреждает.
4. Отображение на экране — текущие показания видны в интерфейсе.
5. Уведомления — при отклонениях приходит предупреждение на экран и телефон.
